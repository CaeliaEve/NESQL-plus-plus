# Native banner patterns

The Et Futurum 2.6.2.25-GTNH reader no longer constructs a
`CachedPatternRecipe`, creates `PositionedStack` objects or changes a borrowed
handler cache. It opens before the GUI-handler factory. Native pattern rules,
color mapping and dye registrations supply logical cells; the pinned native
RecipeAddPattern still verifies matching, first-pattern selection and result NBT.

Mask recipes keep all nine logical cells and blank positions. Catalyst recipes
permit the original optional single dye; absent dye preserves the native color
15 default. Native dye classification precedes catalyst equality. The process
keeps ordered rules, full palette memberships, dye slots and a placement witness.
That witness is not a fixed vanilla crafting-grid predicate: banner location,
catalyst placement and the personal grid remain governed by native matching.
NeoNEI displays a labeled placement example using its own slot components.

The result consumes unit inputs and preserves the input banner's base metadata,
existing pattern history and unrelated NBT, subject to the six-pattern limit.
The native wrong-typed history behavior remains covered by the existing native
test family; no synthetic clean history replaces it.

Four-registration bindings include the actual banner definition/block/item,
pattern/color arrays and Forge ore-dictionary roots. NativeDefinitions guards
roots, ordered pattern members, raw mask/stack/item/tag identities, raw amounts,
NBT and ore facts before/after capture and at sealing. Wildcard dyes use the
finished native item-map reader and bind its readiness, members and facts.
Missing sources, ready-empty, drift, cancellation and closed state are explicit;
close only releases owned copies. Unknown metadata owners fail before invocation.

Three actual Java transport samples cover mask, catalyst-with-dye and
catalyst-without-dye. Their fixture wrapper includes real native ore memberships,
since those memberships are part of this domain's color semantics. Compiler
validates them without weakening its palette gate; shared page queries hydrate
palette and prior-catalyst references. Controlled Catalog/browser checks are
local conformance, not collected native pixels or whole-pack acceptance.
